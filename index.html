CI/CD Website Deployment

A walkthrough of building and deploying a static site using GitHub Actions and AWS EC2.

By Kelani

About this project

This page is the deliverable for a CI/CD assignment. The goal: build a simple website, automate its build and deployment with a CI/CD pipeline, and host it on a cloud-based virtual machine. Every change pushed to the main branch is automatically deployed to this server — you're looking at the result right now.

Tech stack

  • Frontend: HTML & CSS
  • Source control: Git & GitHub
  • CI/CD: GitHub Actions
  • Cloud provider: AWS EC2 (Ubuntu 22.04)
  • Web server: Nginx

Pipeline flow

  1. Developer pushes code to the main branch on GitHub.
  2. GitHub Actions workflow triggers automatically.
  3. The runner checks out the code and prepares it for deployment.
  4. Files are copied over SSH to the EC2 instance using rsync.
  5. Nginx serves the updated site to the public — no manual intervention.

What this demonstrates

Beyond the website itself, this project shows an end-to-end deployment workflow: provisioning a Linux server on AWS, configuring a web server, setting up secure SSH-based deployments with a dedicated user, and wiring a code repository to a live environment with no manual steps in between.
